# grokbot-skills

小星的 Grok Bot 共享技能库（小星、小发、小片等 Bot 共用）。

每个子文件夹是一个技能，`SKILL.md` 写明什么时候用、怎么做。由 Grok Bot 定期从云端技能库同步过来，推送前会扫描，不含 API key、token、密码等私密信息。

| 技能 | 用途 |
| --- | --- |
| multipublish-tuwen | 图文多平台发布（B站 / X / 小红书 / 抖音 / 公众号草稿） |
| multipublish-video | VideoPilot 成片多平台发布（B站 / 小红书 / 抖音 / YouTube） |
